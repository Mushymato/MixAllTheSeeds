# Mix All The Seeds

A small mod about mixed seeds:

- Mixed seeds can now become any in-season non-flower crop.
- Mixed flower seeds can now become any in-season flower crop.
- You can unmix seeds mixed seeds (vanilla as well as item extensions) with the seed maker.

### For Modders

You can add custom field `"mushymato.MixAllTheSeeds/NoMix": "T"` to your `"Data/Crops"` entry to prevent it from appearing in the mixed seeds case.
